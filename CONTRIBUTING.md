# Contributing to VERITAS

## Development Setup

1. Clone the repository
2. Set up backend and frontend per README.md
3. Use `veritas_db` for development; tests use `veritas_test_db`

## Code Style

- Backend: type hints, modular services
- Frontend: TypeScript, functional components
- Do not commit `.env` files

## Academic Integrity

- Mark development fixtures with `development_fixture: true`
- Do not present seed data as experimental evidence
- Use academically responsible language in synthesis outputs
