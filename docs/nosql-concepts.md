# NoSQL Concepts in VERITAS

1. **Document Model** — Debates, claims, evidence as JSON documents
2. **Embedding** — current_synthesis embedded in debate documents
3. **Referencing** — evidence references claims and sources by ObjectId
4. **Aggregation Pipeline** — Analytics across collections ($lookup, $group)
5. **Indexing** — Compound indexes for query performance
6. **Schema Flexibility** — provenance and metadata as flexible subdocuments
7. **Temporal Data** — debate_history as append-only event log
