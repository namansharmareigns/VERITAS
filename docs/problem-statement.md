# Problem Statement

Traditional AI debate systems treat conversations as ephemeral exchanges. When a session ends, the evidence landscape, argument evolution, and provenance of claims are lost.

**Research gap:** There is no persistent, evidence-aware representation that captures how debate positions evolve over time with explainable scoring.

**VERITAS proposed framework:** Represent debates as structured knowledge objects in MongoDB with claims, evidence, contradictions, temporal history, and evidence-weighted synthesis that explicitly represents uncertainty.
